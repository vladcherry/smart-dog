# 02. Список фич

Приоритеты: **P0** — без этого продукта нет (MVP), **P1** — первая версия после MVP,
**P2** — развитие, **P3** — исследовать позже.

## 2.9 Что сознательно НЕ делаем в первой версии

- Соцсеть, лента друзей, чаты владельцев — размывает продукт.
- Магазин товаров — конфликт интересов с рекомендациями по питанию.
- Распознавание породы по фото — красиво, бесполезно для плана.
- Аверсивные методики, электроошейники — противоречат принципам продукта.
