# 04. Профиль и алгоритмы расчёта

Все формулы ниже — стартовая точка плана, которая затем корректируется по факту:
по фактическому весу, кондиции тела и оценкам тренировок.
Ни один расчёт не заменяет ветеринарного врача, и приложение говорит об этом прямо.

---

## 4.1 Вход: профиль

| Поле | Тип | Обязательное | Используется в |
|---|---|---|---|
| Дата рождения | дата | да | возраст → всё |
| Порода | справочник | нет | размерная группа, диапазон взрослого веса |
| Размерная группа | S / M / L / XL | да (выводится из породы) | кривая роста, нагрузка |
| Пол | м / ж | да | поправка ±5 % к прогнозу веса |
| Стерилизация | да / нет / планируется | да | коэффициент калорий |
| Текущий вес | кг | да | RER, прогноз, коридор нормы |
| Корм: ккал на 100 г | число | нет (есть дефолты) | пересчёт калорий в граммы |
| Уровень активности | низкий / средний / высокий | да | поправка калорий и минут выгула |
| Подъём / отбой владельца | время | да | расстановка времён в расписании |
| Уже освоенные команды | чек-лист | нет | стартовая точка в годовом плане |

### Размерные группы

| Группа | Взрослый вес | Примеры | Взросление |
|---|---|---|---|
| **S** | до 10 кг | той, джек-рассел, такса | ~10 мес |
| **M** | 10–25 кг | бордер-колли, корги, коккер | ~12 мес |
| **L** | 25–45 кг | лабрадор, немецкая овчарка | ~15 мес |
| **XL** | свыше 45 кг | алабай, ньюфаундленд, дог | ~18 мес |

Если порода не указана — группа берётся из текущего веса и возраста обратным ходом по кривой (§4.2).

## 4.2 Алгоритм 1. Прогноз взрослого веса и кривая роста

### Шаг 1. Доля взрослого веса по возрасту

Базовая таблица `pct(возраст в неделях, группа)` — доля взрослого веса,
построенная по стандартным ростовым кривым (методология WALTHAM):

| Возраст | S | M | L | XL |
|---|---|---|---|---|
| 8 нед | 22 % | 17 % | 14 % | 12 % |
| 12 нед | 39 % | 31 % | 26 % | 22 % |
| 16 нед | 53 % | 43 % | 36 % | 31 % |
| 20 нед | 65 % | 54 % | 46 % | 39 % |
| 24 нед | 75 % | 63 % | 55 % | 47 % |
| 30 нед | 86 % | 74 % | 66 % | 57 % |
| 36 нед | 93 % | 83 % | 75 % | 66 % |
| 44 нед | 98 % | 91 % | 84 % | 76 % |
| 52 нед | 100 % | 96 % | 91 % | 84 % |
| 65 нед | 100 % | 100 % | 97 % | 92 % |
| 78 нед | 100 % | 100 % | 100 % | 100 % |

Между узлами — линейная интерполяция.

### Шаг 2. Оценка взрослого веса

```
adultWeight_curve = currentWeight / pct(ageWeeks, group)
```

### Шаг 3. Контрольные milestone-формулы (кросс-проверка)

| Группа | Формула |
|---|---|
| S | вес в 6 недель × 4 |
| M | вес в 14 недель × 2.5 |
| L | вес в 20 недель × 2 |
| XL | вес в 24 недели × 2 |
| Универсальная | (вес / возраст в неделях) × 52 — только как грубая проверка |

Если есть замер на нужной вехе, итог — среднее между кривой и milestone-формулой.

### Шаг 4. Ограничение по породе и полу

```
adultWeight = clamp(adultWeight_raw, breedMin × 0.9, breedMax × 1.1)
кобель:  ×1.05
сука:    ×0.95
```

### Шаг 5. Сглаживание по истории замеров

Каждый новый замер даёт свою оценку. Итоговый прогноз — экспоненциальное сглаживание:

```
adultWeight_n = 0.7 × adultWeight_{n-1} + 0.3 × оценка_по_новому_замеру
```

Так прогноз не прыгает от одного «мокрого» взвешивания, но реагирует на устойчивый тренд.
Прогноз не показываем, пока нет минимум 2 замеров с интервалом ≥ 7 дней —
вместо числа показываем диапазон.

### Шаг 6. Коридор нормы и статусы

```
ожидаемыйВес(t) = adultWeight × pct(t, group)
коридор = ожидаемыйВес(t) ± 15 %
```

| Отклонение | Статус | Действие приложения |
|---|---|---|
| −15 % … +15 % | Норма | Ничего |
| +15 % … +25 % | Выше нормы | Снизить калории на 10 %, предложить опрос кондиции |
| > +25 % | Сильно выше | Совет обратиться к ветврачу, калории не режем сами больше чем на 10 % |
| −25 % … −15 % | Ниже нормы | Поднять калории на 10 %, проверить корм и глистогонку |
| < −25 % | Сильно ниже | Прямой совет к ветврачу |

Два замера подряд вне коридора — только тогда меняем план. Один выброс игнорируем.

### Шаг 7. Кондиция тела (BCS 1–9)

Раз в 2 недели — 3 вопроса с картинками: видно ли рёбра, есть ли талия сверху,
есть ли подтяжка живота сбоку.

| BCS | Коррекция калорий |
|---|---|
| 1–3 (худая) | +15 % |
| 4–5 (норма) | 0 |
| 6–7 (полная) | −10 % |
| 8–9 (ожирение) | −20 % и совет к ветврачу |

BCS имеет приоритет над весом: собака может быть «в коридоре», но толстой.

## 4.3 Алгоритм 2. Питание

### Шаг 1. Базовый обмен (RER)

```
RER = 70 × (вес в кг) ^ 0.75     [ккал/сутки]
```

### Шаг 2. Коэффициент жизненного этапа

| Возраст / состояние | Коэффициент k |
|---|---|
| до 4 месяцев | 3.0 |
| 4–7 месяцев | 2.5 |
| 7 месяцев – окончание роста | 2.0 |
| взрослая, интактная | 1.8 |
| взрослая, стерилизованная | 1.6 |

Переходы делаются плавно: коэффициент меняется линейно в течение 2 недель вокруг границы,
чтобы порция не падала в один день на 20 %.

### Шаг 3. Поправки

```
DER = RER × k × активность × кондиция
```

| Фактор | Значение |
|---|---|
| Активность: низкая | ×0.9 |
| Активность: средняя | ×1.0 |
| Активность: высокая | ×1.1 |
| Кондиция | по таблице BCS выше |
| Холодный сезон, уличное содержание | ×1.1 |

### Шаг 4. Граммы

```
граммыВСутки = DER / (ккал на 100 г корма) × 100
граммыНаКормление = граммыВСутки / числоКормлений
```

Округление до 5 г. Если корм неизвестен — дефолт по типу:
сухой 370 ккал/100 г, влажный 90 ккал/100 г, натуралка 150 ккал/100 г,
и приложение честно помечает расчёт как приблизительный.

### Шаг 5. Число кормлений

| Возраст | Кормлений в день |
|---|---|
| до 4 месяцев | 4 |
| 4–6 месяцев | 3 |
| старше 6 месяцев | 2 |

Пользователь может оставить 3 кормления и после 6 месяцев — приложение не спорит,
только пересчитывает граммы.

### Шаг 6. Бюджет лакомств (связка с тренировками)

```
бюджетЛакомств = DER × 0.10
```

Тренировочные лакомства **вычитаются** из дневной нормы корма:

```
граммыКорма = (DER − израсходованоНаЛакомства) / ккал100 × 100
```

Приложение показывает это прямо в карточке кормления:
«Ужин 85 г (−10 г: сегодня было 2 тренировки)».
Это главная причина набора веса у щенков, и никто из конкурентов это не считает.

### Пример

Лабрадор, 4 месяца, 14 кг, сухой корм 380 ккал/100 г, активность средняя, BCS 5.

```
RER  = 70 × 14^0.75 = 70 × 7.24 = 507 ккал
DER  = 507 × 2.5 × 1.0 × 1.0 = 1268 ккал
Граммы = 1268 / 380 × 100 = 334 г/сутки
Кормлений = 3 → по 111 г → округляем до 110 г
Бюджет лакомств = 127 ккал ≈ 33 г корма или ~15 г сыра
```

## 4.4 Алгоритм 3. Выгул

### Структурированная нагрузка (то, что мы планируем)

```
минутНаПрогулку = clamp(5 × возраст в месяцах, 10, максимумГруппы)
прогулок в день = 2 (утро, вечер)
```

Это известное «правило 5 минут на месяц жизни, дважды в день» — консервативная норма
для растущих суставов. Оно про **целенаправленную нагрузку**: ходьбу на поводке,
тренировку, игру. Свободное движение по двору и дому в норматив не входит.

| Группа | Максимум на прогулку до конца роста |
|---|---|
| S | 45 мин |
| M | 60 мин |
| L | 60 мин |
| XL | 45 мин (самые уязвимые суставы) |

### После окончания роста

```
минутНаПрогулку = 45–60, прогулок 2, плюс 1 длинная прогулка в выходной
```

### Ограничения ударной нагрузки

До окончания роста (см. таблицу групп в §4.1) приложение не предлагает и предупреждает про:
бег рядом с велосипедом, прыжки через барьеры, длинные пробежки, лестницы вниз в большом объёме,
игру в апорт с резкими разворотами на скользком полу.

### Туалетные выходы (отдельно от прогулок)

```
максимумУдержания в часах ≈ возраст в месяцах + 1   (потолок 8 часов)
```

Плюс обязательные выходы: сразу после сна, через 15–30 минут после еды, после активной игры.
Эти выходы короткие (5–10 минут), в норматив нагрузки не входят и в ленте дня
показаны как вспомогательные.

### Карантин после первой вакцинации

Если в профиле указана дата первой прививки и с неё прошло меньше 10–14 дней,
уличные прогулки заменяются на «прогулки на руках» и домашние тренировки,
а в ленте дня появляется поясняющая карточка.

## 4.5 Алгоритм 4. Тренировка внутри выгула

### Длительность сессии

```
минутТренировки = clamp(1.5 × возраст в месяцах, 3, 12)
навыков за сессию = 2–3
```

Короткие сессии эффективнее длинных: внимание щенка 2 месяцев держится ~2 минуты.

### Состав блока

Каждая прогулка получает блок из:
1. **1 навык в активном изучении** (стадия LEARNING) — основная работа;
2. **1 навык на отработке** (PRACTICE) — в отвлечениях улицы;
3. **0–1 навык на поддержке** (MAINTENANCE / MASTERED) — короткая проверка по интервалу повторения.

Утро и вечер различаются: утром — новый материал (щенок свежий),
вечером — закрепление и работа в отвлечениях.

### Стадии навыка

| Стадия | Смысл | Повторов за сессию | Частота |
|---|---|---|---|
| **NEW** | В очереди, ещё не начат | — | — |
| **LEARNING** | Учим с нуля, дома и в тихом месте | 8 | обе прогулки |
| **PRACTICE** | Отрабатываем в отвлечениях, растим 3D | 5 | 1 раз в день |
| **MAINTENANCE** | Работает надёжно, поддерживаем | 3 | через день |
| **MASTERED** | Освоен, всплывает по интервалам | 2 | 1 / 3 / 7 / 14 / 30 дней |

### Оси сложности (3D)

У каждого навыка три оси, которые растут **по одной за раз**:

| Ось | Пример шкалы |
|---|---|
| **Дистанция** | 0.5 м → 1 м → 3 м → 5 м → 10 м → вне поля зрения |
| **Длительность** | 2 с → 5 с → 10 с → 30 с → 1 мин → 3 мин |
| **Отвлечения** | дома тихо → дома с семьёй → двор → тихая улица → парк → парк с собаками |

Правило: поднимая одну ось, две другие откатываем на шаг назад.

## 4.6 Алгоритм 5. Прогрессия по оценкам («правило пяти пятёрок»)

### Вход

После каждой прогулки — оценка 1–5 по каждому отработанному навыку.

| Оценка | Значение | Формулировка в интерфейсе |
|---|---|---|
| 5 | Выполнил с первого слова в 4+ случаях из 5 | Отлично |
| 4 | Выполняет, но с задержкой или со второго раза | Хорошо |
| 3 | Через раз, нужна помощь | Нормально |
| 2 | Почти не выполняет в этих условиях | Слабо |
| 1 | Не понимает, сорвалось | Плохо |

### Правила

```
оценка 5      → streak += 1
оценка 4      → streak не меняется (прогресс стоит, отката нет)
оценка ≤ 3    → streak = 0
две оценки ≤ 2 подряд → откат стадии на шаг назад + ремедиация
```

### Повышение стадии

```
if streak >= 5 и пятёрки получены минимум в 3 разных днях:
    стадия = следующая стадия
    streak = 0
    повторы и частота снижаются по таблице стадий
    проверяем слоты → при наличии свободного открываем новую команду
```

### Слоты активных навыков

- Одновременно **изучаем не больше 2 команд** (стадия LEARNING).
- Всего в работе (LEARNING + PRACTICE) — **не больше 5 навыков**.
- Новая команда открывается, как только выполнены оба условия: изучаемых меньше 2
  и в работе меньше 5. На практике это значит, что **каждое повышение стадии
  с «изучаем» на «отработку» открывает следующую команду** — ровно то, чего ждёт владелец
  после пяти пятёрок: повторов по знакомой команде стало меньше, и появилась новая.
- Уход навыка в MAINTENANCE освобождает слот в пуле окончательно.

### Разблокировка новой команды

```
при освобождении слота (изучаемых < 2 И в работе < 5):
    кандидаты = навыки стадии NEW, у которых
        возраст собаки >= минимального возраста навыка
        И все предпосылки навыка находятся минимум в стадии PRACTICE
    следующий = первый кандидат в порядке годового плана
```

Пример предпосылок: «Рядом» требует «Внимание/имя» и «Ходьба на провисшем поводке»;
«Экстренный подзыв» требует «Ко мне» в стадии MAINTENANCE.

### Ремедиация (что делает откат)

При откате приложение не просто снижает стадию, а **упрощает критерий**:

1. Откатить самую высокую из трёх осей 3D на два шага назад.
2. Вернуть повторы на уровень LEARNING.
3. Показать карточку: «“Ко мне” в парке пока рано. Возвращаемся во двор на 3 дня» —
   с прямой ссылкой на нужный шаг протокола в статье.
4. Никакого негатива в формулировках: откат — это часть плана, а не провал.

### Защита от накрутки

- Оценка запрашивается только после реально завершённой прогулки (таймер шёл ≥ 3 минут).
- Пять пятёрок засчитываются, только если они получены **минимум в 3 разных днях** —
  нельзя «прокликать» уровень за один вечер.
- Если навык поднялся до MASTERED, а затем получил две оценки ≤ 3 на проверках —
  он возвращается в MAINTENANCE. Надёжность важнее красивой полки достижений.

### Итоговый эффект

По мере роста собаки объём тренировок **на единицу навыка** падает,
а набор навыков расширяется. Общая длительность тренировок остаётся постоянной
и не превышает возрастной нормы — растёт только их сложность.

## 4.7 Еженедельный пересчёт плана

Каждый понедельник в 03:00 (локально):

1. Обновить возраст, пересчитать `pct`, коридор нормы, статус роста.
2. Пересчитать RER, DER, граммы, число кормлений; при смене коэффициента — предупредить.
3. Пересчитать минуты выгула.
4. Пересчитать длительность и состав тренировочных блоков.
5. Если фаза годового плана сменилась — показать карточку «Началась новая фаза».
6. Собрать недельный отчёт: прогулки, средние оценки, разблокированные команды, динамика веса.

Если пользователь вручную изменил время или граммы — его значения не перетираются,
но в разделе «Рекомендации» появляется мягкая подсказка с расхождением и кнопкой «Применить».
