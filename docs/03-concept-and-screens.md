# 03. Концепция и экраны

## 3.1 Главная идея

> **Открыл приложение — увидел план на сегодня. Больше ничего делать не нужно.**

Всё остальное — второй уровень: прокрутил ниже или ушёл в другую вкладку.
Приложение никогда не спрашивает «что будем делать сегодня» — оно уже решило и показало.

Три уровня глубины:

1. **Уровень 1 — верх экрана «Сегодня».** Ближайшая задача крупной карточкой: «Через 25 минут — утренний выгул, 20 минут, тренируем “Ко мне”». Один тап — начать.
2. **Уровень 2 — прокрутка вниз.** Весь день лентой, затем блоки: навыки в работе, рост и вес, подборка статей.
3. **Уровень 3 — вкладки.** План на неделю/год, Учебник, Расписание, Профиль.

## 3.2 Карта экранов

```
Таб-бар (4 вкладки)
├── Сегодня        ← стартовый экран
├── План           ← неделя → фаза → год
├── Учебник        ← статьи и протоколы команд
└── Профиль        ← собака, расписание, настройки, прогресс

Модальные:
├── Режим прогулки (полноэкранный)
├── Оценка после прогулки (шторка снизу)
├── Онбординг (первый запуск)
├── Ввод веса
└── Карточка навыка
```

## 3.3 Экран «Сегодня»

Сверху вниз:

| Блок | Содержание |
|---|---|
| **Шапка** | Кличка + фото, возраст («4 месяца 2 недели»), кольцо прогресса дня, серия дней подряд |
| **Следующая задача** | Крупная карточка: тип, время, длительность, что тренируем. Кнопка «Начать» |
| **Лента дня** | Вертикальный таймлайн со всеми событиями дня. Прошедшие — свёрнуты и приглушены, текущее — подсвечено, будущие — обычные |
| **Навыки в работе** | 3 чипа с прогрессом: «Ко мне · 3/5 пятёрок», «Место · стадия отработки» |
| **Рост и вес** | Мини-график с коридором нормы + «Взвесить» |
| **Учебник — что почитать сегодня** | 2–3 карточки статей, релевантных текущей фазе и сегодняшним навыкам |
| **Совет дня** | Одна короткая карточка из «Рекомендаций» |

### Типовая лента дня (щенок 4 месяцев, 2 выгула)

```
07:00  ●  Утренний выгул · 20 мин
          └── Тренировка: «Ко мне» ×5, «Сидеть» ×3        [Как учить]
07:30  ●  Завтрак · 95 г
11:00  ○  Туалетный выход · 5–10 мин
14:00  ○  Туалетный выход · 5–10 мин
18:30  ●  Вечерний выгул · 20 мин
          └── Тренировка: «Ко мне» ×5, «Рядом» ×4         [Как учить]
19:00  ●  Ужин · 95 г
22:00  ○  Последний туалетный выход · 5 мин
```

Легенда: `●` — обязательное событие плана, `○` — вспомогательный выход.

## 3.4 Режим прогулки

Полноэкранный режим, который запускается кнопкой «Начать»:

1. **Таймер** с целевой длительностью и мягким предупреждением при перегрузке («для 4 месяцев 20 минут достаточно»).
2. **Карточки тренировки** — свайп по навыкам, у каждого: шаг протокола, число повторов, счётчик выполненных.
3. **Кликер** — крупная кнопка внизу.
4. **Быстрые отметки** — «пописал», «покакал», «встретили собаку», «испугался» (для дневника социализации).
5. **Завершить прогулку** → шторка оценки.

## 3.5 Оценка после прогулки

Шторка снизу, занимает не больше 15 секунд:

```
Как прошло с «Ко мне»?

  1        2        3        4        5
 плохо   слабо   норм   хорошо  отлично

[ Пропустили этот навык ]
```

- По одному экрану на каждый отработанный навык (обычно 2–3).
- Под шкалой — подпись-подсказка, что значит «отлично»: «выполнил с первого слова в 4 случаях из 5, на дистанции 5 метров».
- После последней оценки — экран результата: что изменилось (прогресс, откат, разблокировка новой команды).

## 3.6 Экран «План»

Три уровня вложенности:

- **Неделя** (по умолчанию) — 7 дней, тема недели, цель недели, контрольная точка.
- **Фаза** — одна из 5 фаз года: срок, задачи, чек-лист «что должно быть к концу фазы».
- **Год** — вертикальная дорожка 52 недель, пройденное отмечено, будущее видно наперёд.

## 3.7 Экран «Учебник»

- Категории: **Базовые команды**, **Быт и режим**, **Поведение и проблемы**.
- Карточка статьи: обложка, время чтения, тег фазы («актуально сейчас» / «пригодится позже»).
- Внутри статьи: пошаговый протокол с критериями перехода, частые ошибки, «сколько это занимает», кнопка «Добавить в тренировку».

## 3.8 Экран «Профиль»

- Карточка собаки: фото, возраст, вес, прогноз взрослого веса.
- **Расписание** → отдельный экран с настройками времени и разделом «Рекомендации» (см. документ 06).
- **Прогресс**: график веса, полка навыков, серия дней, недельный отчёт.
- **Здоровье**: прививки, обработки, смена зубов, стерилизация.
- **Настройки**: уведомления, единицы измерения, тема, семейный доступ.

## 3.9 Онбординг (8 шагов, до 90 секунд)

| Шаг | Вопрос | Зачем |
|---|---|---|
| 1 | Кличка и фото | Персонализация |
| 2 | Дата рождения (или «примерно N месяцев») | Возраст — главный вход всех формул |
| 3 | Порода или размерная группа | Кривая роста, ограничения нагрузки |
| 4 | Пол, стерилизация | Коэффициент калорий |
| 5 | Текущий вес | Прогноз взрослого веса, RER |
| 6 | Корм: ккал на 100 г (или «не знаю» → среднее по типу) | Пересчёт калорий в граммы |
| 7 | Уровень активности и во сколько встаёте/ложитесь | Расстановка времён в расписании |
| 8 | Что уже умеет (чек-лист команд) | Стартовая точка в годовом плане |

**Финал онбординга — не «Готово», а сразу экран «Сегодня» с собранным планом**
и коротким объяснением: «Мы рассчитали: 2 выгула по 20 минут, 3 кормления по 95 г,
начинаем с команд “Имя”, “Сидеть”, “Ко мне”. Всё можно поправить в расписании».

## 3.10 Сущности данных (без кода)

| Сущность | Ключевые поля |
|---|---|
| Dog | кличка, дата рождения, порода, размерная группа, пол, стерилизация, фото |
| WeightEntry | дата, вес, источник (ручной/весы) |
| FoodProfile | тип корма, ккал/100 г, бренд |
| Schedule | времена выгулов, времена кормлений, число кормлений, источник (рекомендация/ручное) |
| DailyPlan | дата, список событий (выгул, кормление, туалет, тренировка) |
| PlanEvent | тип, время, длительность/граммы, статус, привязанный тренировочный блок |
| Skill | название, категория, фаза, протокол шагов, критерии 3D |
| SkillProgress | стадия, серия пятёрок, повторы, дата следующего повтора, история оценок |
| WalkSession | старт, финиш, длительность, отметки, оценки по навыкам |
| Article | заголовок, категория, фаза, шаги, связанные навыки |
| Recommendation | правило, текст, действие «применить» |
